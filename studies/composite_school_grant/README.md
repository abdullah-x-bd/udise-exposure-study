# Composite School Grant Study

This folder contains a self-contained longitudinal study of India's Composite School Grant using UDISE+ school-level microdata from 2018-19 through 2025-26.

## Core question

Does a discontinuous increase in school-level discretionary grant entitlement, generated by enrolment-based Composite School Grant rules, produce measurable improvements in independently recorded school conditions?

The study will not assume that a nominal policy threshold generates treatment. It first tests whether lagged enrolment predicts a discontinuous change in grant receipt or expenditure. Causal analysis proceeds only for thresholds and years with a credible first stage and acceptable continuity/manipulation diagnostics.

## Data

Private Hugging Face UDISE+ microdata, organised under `raw/<academic-year>/` for eight consecutive years from 2018-19 to 2025-26.

## Workspace

- `scripts/` reproducible study code
- `config/` policy and variable configuration
- `docs/` design notes and final findings
- `outputs/` generated locally/in GitHub Actions and uploaded as workflow artifacts

## Planned stages

1. Schema and grant-variable discovery across all eight UDISE+ vintages.
2. Cross-year variable harmonisation and school-code panel audit.
3. Empirical reconstruction of the grant assignment rule and lag structure.
4. First-stage discontinuity tests at candidate enrolment cutoffs.
5. Sorting/bunching and covariate-continuity diagnostics.
6. Local-linear RD and panel threshold-crossing/event-study estimates for independently recorded outcomes.
7. Placebo cutoffs, bandwidth sensitivity, functional-form sensitivity, state heterogeneity, and attrition checks.
8. Final policy interpretation and reproducible report.

## Identification rule

No coefficient will be labelled causal merely because it is statistically significant. A threshold enters the causal analysis only if the data show a policy-relevant discontinuity in treatment and the design survives the pre-specified validity diagnostics.
